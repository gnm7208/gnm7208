- 💰 **[Kipato](https://github.com/gnm7208/kipato)** — offline-first income record for informal workers; log cash earnings with no signal, import M-PESA history, generate a verifiable income statement for SACCOs and lenders. React 19 · Flask · PostgreSQL. Live: [app](https://kipato.vercel.app)
- 🧾 **[Hesabu](https://github.com/gnm7208/Hesabu)** — chama reconciliation; turns a savings group's M-PESA messages into a dispute-proof ledger with arrears and monthly statements. React · TypeScript · Flask · PostgreSQL. Live: [app](https://hesabu-sigma.vercel.app) · [API](https://hesabu-api.onrender.com)
- 🔧 **[Fundi Connect](https://github.com/gnm7208/fundi-connect)** — verified informal-services marketplace with M-PESA escrow; the customer's money is locked with the platform, not handed to the fundi. React 19 · TypeScript · Flask 3. Live: [app](https://fundi-connect-pi.vercel.app) · [API](https://fundi-connect-api.onrender.com)
- 🛍️ **[Soko](https://github.com/gnm7208/Soko)** — local marketplace: listings, search, maps, delivery, real-time chat, ratings and payments. React · TypeScript · Flask · Socket.IO · Stripe. Live: [app](https://soko-app-eight.vercel.app) · [API](https://soko-api-24sn.onrender.com)
- 🌱 **[AgriLink](https://github.com/gnm7208/Agrilink)** — agricultural super app (team project, backend developer). React · Flask · PostgreSQL. Live: [app](https://agrilink-self.vercel.app) · [API](https://agrilink-7uhu.onrender.com)
- 🛒 **[Fiti Electronics](https://github.com/gnm7208/Fiti_Electronics)** — mini e-commerce web app (solo build). JavaScript · JSON Server. Live: [Netlify](https://fiti.netlify.app) · [Render](https://fiti-electronics.onrender.com)
- 📱 **[Fint](https://github.com/gnm7208/Fint)** — Android school app in 100% Kotlin (eMobilis MIT capstone). M-Pesa integration on the roadmap.
- 🧠 **[Tubonge](https://github.com/gnm7208/Tubonge)** — online therapy platform for Kenya: licensed therapists, M-Pesa booking, video sessions. Next.js · Supabase · Daily.co. Build plan complete, implementation under way.
