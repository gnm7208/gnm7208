## George Mukirai

Full-stack developer in Nairobi, Kenya.

I build software for the parts of the economy that run on cash, M-PESA and trust —
chamas, fundis, boda riders, market traders, smallholder farmers. Most of my work
starts from the same question: what does this person currently do with a notebook,
and what would it take to make the digital version faster than the notebook?

I ship end to end — schema, API, interface, deploy.

`Flask` · `PostgreSQL` · `React` · `TypeScript` · `Python` · `Linux`

---

### Live projects

**[Kipato](https://github.com/gnm7208/kipato)** — an offline-first income record for informal workers. Log cash earnings with no signal, import M-PESA history, and generate a verifiable income statement a SACCO or lender can open without an account.
React 19 · Flask · PostgreSQL · IndexedDB outbox → **[kipato.vercel.app](https://kipato.vercel.app)**

**[Hesabu](https://github.com/gnm7208/Hesabu)** — chama reconciliation. Parses a group's M-PESA messages into a dispute-proof ledger with contribution tracking, arrears and monthly statements, so the treasurer stops matching SMS to names by hand.
React + TypeScript · Flask · PostgreSQL → **[hesabu-sigma.vercel.app](https://hesabu-sigma.vercel.app)**

**[Fundi Connect](https://github.com/gnm7208/fundi-connect)** — a verified marketplace for informal services with M-PESA escrow. The customer's money is locked with the platform, not handed to the fundi. Identity verification, geo-search, ratings, Daraja integration.
React 19 + TypeScript · Flask 3 · SQLAlchemy 2 → **[fundi-connect-pi.vercel.app](https://fundi-connect-pi.vercel.app)**

**[Soko](https://github.com/gnm7208/Soko)** — a local marketplace: listings, search, maps, delivery, real-time chat, ratings and payments.
React + TypeScript · Flask · PostgreSQL · Socket.IO · Stripe / Flutterwave → **[soko-app-eight.vercel.app](https://soko-app-eight.vercel.app)**

**[AgriLink](https://github.com/gnm7208/Agrilink)** — an agricultural super app connecting farmers with experts through posts, communities and messaging. Team project; I worked on the backend.
React 19 · Flask · PostgreSQL · Cloudinary → **[agrilink-self.vercel.app](https://agrilink-self.vercel.app)**

**[Fiti Electronics](https://github.com/gnm7208/Fiti_Electronics)** — an electronics storefront with cart, filtering and checkout flow.
JavaScript · JSON Server → **[fiti.netlify.app](https://fiti.netlify.app)**

> The APIs run on free Render instances and cold-start after inactivity — first
> request can take about 50 seconds. Give the login screen a moment.

Also in the workshop: **[Fint](https://github.com/gnm7208/Fint)**, a 100% Kotlin Android school-management app with M-PESA fee payments on the roadmap, and **[Tubonge](https://github.com/gnm7208/Tubonge)**, an online therapy platform for Kenya currently at blueprint stage.
